The index.html file is to help anyone who gets locked out of the Hyperliquid front end, to allow them to recover funds that are staked.

It also allows you to send usdc or hype to a new address. Note you need to switch to manual account mode to enable the send functionality, it won't work in unified mode.

The website link is https://kriptoe.github.io/Hyperliquid_recovery_tools/

People have reported being blocked from the front end by chain analysis due to their wallet receiving transactions from banned exchanges or can just be from a address poisoning tx

If you want further support you can try contacting @Hy_Purr_liquid on X
